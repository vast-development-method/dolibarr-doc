# Reconcile an employee's leave balance

Start with the employee, leave type and two endpoint balances. The sum of changes recorded between them should explain their difference. Compare each change with the state of its request, the approved working-day quantity and the last processed month. The employee's weekly employment hours describe a working arrangement. The standard leave counter measures days and its monthly credit comes from the leave type.
