**A verified documentation difference.** The Resources wiki's module information box lists module ID 0. The 24.0.3 resource descriptor declares **63000**. Use the descriptor and the [module inventory](../coverage/modules.json) when mapping installation IDs. For the booking conflict rule, follow the resource assignment screen: it performs the overlap check before adding the relationship. Looking only at the resource class would miss that caller-level rule.
