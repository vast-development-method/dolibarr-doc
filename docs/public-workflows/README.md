# Public self-service workflows

Use the visitor's intended action to identify the record that should change. An event acknowledgment can represent a proposed talk, a booth request or a completed attendee registration. A payment page can be reached from a new member application or an existing member. Reconciliation depends on the originating record and its own lifecycle.

| Visitor action | Entry conditions | Persistent effect and next step |
| --- | --- | --- |
| Apply for membership | Public enrollment is enabled, an active or configured membership type is selected, and identity and country requirements are met. | A draft member and optionally a linked party. Acknowledgment or dues checkout follows. [Application and directory](membership-and-giving.md) |
| Renew a recognized membership | Existing-member recognition is configured and a validated member is uniquely matched. | The visitor confirms whether to go to that member's payment. A funded renewal is handled by the subscription workflow. [Member recognition](membership-and-giving.md) |
| Browse members | Public directory enabled. The list selects validated, public members of the chosen entity. | Read-only directory and profile. The list can include a member with lapsed dues. [Directory disclosure](membership-and-giving.md) |
| Pledge a gift | Public donations enabled, requested minimum met, project resolved if attributed. | A draft donation for the stated amount. Optional checkout continues against that gift. [Gift intake](membership-and-giving.md) |
| Propose a talk or booth | The event landing page advertises the choice. The submitter supplies an organization, named contact and proposal. | A program item and speaker or responsible-contact assignment. A priced booth also creates a draft customer invoice. [Contributor workflow](contributors-and-conference-votes.md) |
| Vote on a proposed session | The project offers voting and the candidate is in its public conference list. | Increment the program item's vote count. A repeat for that candidate in the same session is recognized. [Program voting](contributors-and-conference-votes.md) |
| Attend a whole event or a session | The entry is for a validated project or confirmed program item in the registration context. | Create or reuse an attendee scoped to the event or session and email. Free registration validates the attendee. Paid registration prepares its invoice and payment path. [Admission, capacity and repeat enrollment](../specification/planning/event-capacity-registration-and-payments.md) |
| Open a support request | Public ticket intake enabled. The origin email must be valid. A configured known-address policy can require an active contact linked to a party. | A new ticket has its own business reference and public tracking identifier. Email and the participant's relationship govern access to an existing conversation. [Ticket conversation and closure](../specification/people-and-services/ticket-routing-and-conversation.md) |
| Reply to or close a support request | The visitor qualifies as a participant for the tracked ticket. The open-ticket view offers reply and closure controls. | Reply adds a customer-visible message. Confirmed closure uses the resolved-close operation. Private staff notes stay outside the public thread. [Public access and resolution](../specification/people-and-services/ticket-routing-and-conversation.md#public-access-and-resolution) |
| Sign a document or decline an offer | Document-specific invitation and an existing document. An offer must be issued for online acceptance. | Signed document evidence plus the family-specific result. An offer records a commercial decision, while a contract or shipment records receiver signature state. [Document decisions and evidence](document-decisions.md) |
| Answer a public poll | The survey admits modifications within its date and state window. The participant name must be available for that survey. | Stores a ballot with one answer per ordered choice. Visibility and commenting have their own rules. [Survey participation and results](../communications/surveys.md) |
