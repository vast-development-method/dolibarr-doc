# Operator reports and record lists

Choose a report by the business event and the unit it counts. Five units on an invoice, five units allocated to a shipment and five orders containing an item describe different populations. The selected period, role and page can change which records contribute.

| Operator question | Where to look |
| --- | --- |
| Which offers, orders, invoices, templates, shipments and receipts actually contain this catalogue item? Which date controls the search? | [One item's commercial history](item-document-history.md) |
| Did this month's change come from a higher quantity, more documents, a credit, or a new document still in draft? | [Catalogue activity by month](catalogue-monthly-measures.md) |
| Which customer order lines match a product, date, warehouse, amount, billing state or current availability? | [Customer order lines across the portfolio](customer-order-line-list.md) |
| Who represents the customer, worked on the document, created the invoice or receives a share of its margin? | [Reading sales figures by person](people-and-sales-attribution.md) |
| Which public or private projects can this operator list, and how do membership, opportunity stage, dates and categories narrow the selection? | [Project visibility and opportunity filters](project-list-and-opportunity-filters.md) |

It includes the expected monthly chart, document counts, signed invoice quantity, shipped quantity and open order quantity. A second result shows what changes on adding a draft invoice.
